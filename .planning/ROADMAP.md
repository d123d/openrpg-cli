# Roadmap

## Phase 1 — Clean Fork

Status: complete

- independent package/repository/branding
- SRD-only data bundle
- integrity manifest and audit
- compendium CLI and dice

## Phase 2 — Normalized Rules API

- typed entity models
- relationship joins for class features, traits, spell lists, actions
- stable query API

## Phase 3 — Character Engine

- SRD-only character creation
- equipment, feats, spells, progression
- deterministic saves

## Phase 4 — Combat Engine

- initiative, attacks, damage, conditions, rest
- SRD creatures and encounter math

## Phase 5 — External Play Packs

- user-owned external pack format
- no bundled setting/adventure content
- schema validation and content-origin labels
